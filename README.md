# Clase S4 Sesión I Kickoff - Ejercicios DOM en 8 Pasos

Ejercicios progresivos para aprender manipulación del DOM desde cero.

## Tecnologías Utilizadas

- **HTML5**: Estructura semántica
- **CSS3**: Flexbox para layouts. Responsive
- **JavaScript ES6**:
  - DOM manipulation
  - Event listeners
  - Array methods (map, filter)
  - Arrow functions
  - Template literals
